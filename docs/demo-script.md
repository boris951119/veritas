# veritas 演示口述稿（约 5 分钟）

> 对着工作台练。先有案例产物（在线跑过，或 `python scripts/demo_offline.py`）。  
> 定位一句话：**采集、监测、编排是发榜方已有的；veritas 是后面的可信闸——结论过关、出事能查、能接到现有智能体。**

开场先背这一句：

**可信不是模型说得更像，而是三件事当场能查：依据摸得回原文，责任说得清是谁主张的，改过的记录改一字就红。**

---

## 开场（30 秒）

各位老师好。发榜方已经在舆情、开源情报、风控里部署了智能体，痛点是结论黑箱、简单投票出错。

veritas 不做又一套采集平台，做的是**可信研判中枢**：多角色独立写结论 → 挂证据到原文 → 冲突裁决且少数意见保留 → 全程入账本。

今天主案例是**谣言 vs 官方通报**（开源情报）：三份自媒体说停工，一份监管通报说不实。  
多数票站谣言，程序按证据强度翻案，谣言进少数意见、不删除。

---

## 动作一：翻案 + 点开原文（70 秒）

打开「谣言 vs 官方通报」。看多数结论：官方通报——传闻不实。  
再看少数意见：自媒体仍主张停工——**吵输了还在**。

点开多数结论旁的引文：是监管通报里的原句，不是模型转述。对不上就打回。

（可选）关系图「过程回放」：独立视角 → 结论证据 → 冲突质证 → 裁决 → 锚定信源。

---

## 动作二：无源数字会亮灯（70 秒）

在结论里加一个原文没有的数，比如「良率已达 99%」，保存。

机械核对**亮黄灯**；综合意见跟着改后的结论重写。人可以改，编出来的数字不会假装没发生。

---

## 动作三：因果空头会掉分（40 秒，加分项）

右侧引导点「3 改成因果」，或把一条证据的关系从「相关」改成「因果」。  
若引文里没有「因为 / 导致」这类机制词，**黄牌亮起，因果加成取消**。  
我们校验因果声称，不做因果发现。

---

## 动作四：账本 + 可带走的审计包（50 秒）

右侧引导点「4 账本与带走」：  
点「核验账本」——绿。点「演示篡改」——内存改一字立刻红，磁盘不动。

再点「导出审计包」：报告、链、核验摘要打成 zip，**信任可以移交**，不只本机绿灯。  
现场默认已带演示 HMAC 密钥；核验提示「已签名」时，外人可用同一密钥独立验。

（加问再点）「外部假引文入卷」：第三方交假引文 → 打回并写明提交方，磁盘不动。

---

## 收束（30 秒）

1. 结论必须挂得住原文；  
2. 人可改，无源数字与空头因果会亮灯；  
3. 日志可验，审计包可带走；第三方智能体经 MCP 入卷，假引文照样打回，打回记录写明提交方。

谢谢各位老师。

## 被问到再答（不要主动讲）

| 问 | 答一句 |
|---|---|
| 和群聊 Agent 有何不同 | 独立写、再裁决、输的留着、引文对不上就打回 |
| 0.73 是什么 | 规则分，不是概率；能拆开看、改完能重算 |
| 因果呢 | 标了因果但引文里没有机制说明，就不加分——现场可改标注演示 |
| 怎么接到你们系统 | 点「外部假引文入卷」：灵境式助手交假引文 → 打回并写明提交方；或 `python scripts/demo_external_ingest.py` |
| 换模型怎么办 | 先探测守不守纪律，不守就收紧规则并打回重写 |
| 是不是只会这个题 | 切数据中台交付风险 / 谣言 vs 官方，同一套工作台 |
| 测过真公告吗 | 恒兴新材 8 份公告 10 问，约 9.5/10（`eval/hengxing-defense.md`） |
| 多数投票会不会压过官方通报 | 切 rumor-vs-official：程序按证据强度翻案，谣言进少数意见 |
| 为什么不自己做监测 | 监测是发榜方已有能力；我们补的是结论过关与责任可查 |

## 录的时候别做的事

- 不要演成「迷你天目 / 又一套舆情采集」。  
- 不要逐个介绍闸族名单。  
- 动作二必须真的改出无源数字；动作三最好真改一次关系标注。  
- 超时砍开场，动作一、二、四不能砍；动作三可压缩为一句。
