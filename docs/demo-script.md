# veritas 演示口述稿（约 4 分 30 秒）

> 对着工作台练。先有案例产物（在线跑过，或 `python scripts/demo_offline.py`）。  
> 只做三个动作。其余能力等评委问再答，不要主动展开闸族名单。

开场先背这一句：

**可信不是模型说得更像，而是三件事当场能查：依据摸得回原文，编的数字会亮灯，改过的记录改一字就红。**

---

## 开场（25 秒）

各位老师好。veritas 做的是多智能体研判，但我们不比谁写得更长。

多个角色先**各自独立写结论，互相看不见**。意见对立就质证、裁决，**落败的意见留着，不删**。  
最后有一份综合意见，正面回答议题。

今天只演示三下。案例是固态电池能不能规模上车。

---

## 动作一：点开原文（70 秒）

请看一条结论旁边的引文。我点开它。

这不是模型的转述，是**从来源段落里逐字摘出来的**。对不上原文的引文，进不了正式报告，会被打回。  
这一步不靠模型感觉像不像，靠程序比对。

上面那条综合意见，是把已经过关的结论收成一句回答。每一点都能点回对应结论。

（若评委看少数意见：指一下「少数意见」区，说「吵输了还在，方便人再看一眼」。然后回到动作二。）

---

## 动作二：改一个资料里没有的数字（80 秒）

我在这条结论里加一个原文没有的数，比如「良率已达 99%」，保存。

两件事同时发生：

1. 机械核对**亮黄灯**——这个数在所引原文里找不到；  
2. 顶部综合意见**跟着改后的结论重写**，不会还显示改之前那句话。

人可以改。改完，编出来的数字不会假装没发生。操作记进日志。

演示完如果要恢复，点「重置」。重置也入链。

---

## 动作三：改一字即红（50 秒）

点「校验防篡改链」，现在是绿的。

点「篡改演示」。系统只在**内存副本**里改一个字段，磁盘文件不动。  
诚实的是绿，改过的立刻红。

**改一字即红。** 研判日志是账本，不是一份随便能改的文本。

---

## 收束（25 秒）

三句话收住：

1. 结论必须挂得住原文，挂不住就打回；  
2. 人可以改，编的数字会亮灯，综合意见跟着变；  
3. 日志可以验，改一字就红。

编队可以换成别的角色，第三方智能体也可以按同一套契约把结论送进来，假引文照样过那道闸。  
今天先看到这三个动作。谢谢各位老师。

---

## 被问到再答（不要主动讲）

| 问 | 答一句 |
|---|---|
| 和群聊 Agent 有何不同 | 独立写、再裁决、输的留着、引文对不上就打回 |
| 0.73 是什么 | 规则分，不是概率；能拆开看、改完能重算 |
| 因果呢 | 标了因果但引文里没有机制说明，就不加分 |
| 换模型怎么办 | 先探测这个模型守不守纪律，不守就收紧规则并打回重写 |
| 是不是只会这个题 | 切到数据中台交付风险，同一套工作台 |
| 多数投票会不会压过官方通报 | 切 rumor-vs-official：桩故意把票判给谣言，程序按证据强度翻案，谣言进少数意见 |
| 0.23 那么低还展示？ | 规则分会拆开看；少数意见留着，不靠把分做高来假装一致 |
| 手机号会不会上台 | 展示层脱敏，磁盘案卷和哈希链仍是原文 |

## 录的时候别做的事

- 不要逐个介绍计算闸、对撞台账、BM25、OCR。  
- 不要在没亮灯时声称「系统很严」。动作二必须真的改出一个原文没有的数字。  
- 超时就砍开场，三个动作一个都不能砍。
